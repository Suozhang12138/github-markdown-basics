# T03 设计说明（1.3 设计方向）

> 1.3（设计方向）与 1.4（前端方向）二选一，本人选择做 1.4。本题未提交设计图。

## 一、选择理由

1. **可验证性**：设计图只能证明"我想到了"，实现能证明"我做到了"，而且可以被命令反复验证（构建断言、渲染自检、反向验证）。对基础薄弱、需要外部判据的我来说，后者的反馈更硬，也更难自我欺骗。
2. **时间与深度的取舍**：与其在两个方向都交出半成品，不如把有限的时间投在一个方向上做深。
3. **代价**：不做 1.3，就放弃了"用户是谁、在什么场景、为什么这样设计"这一层表达。这是我的选择，不是疏忽。

## 二、设计思路（未提交设计图，仅作说明）

题目给的字段是 `JobId / JobName / Province / City / Education / Experience / Salary / CompanyType`。面向求职者做职位画像，我会按「先定位 → 再比较 → 最后决策」三段组织：

1. **定位**：城市 × 岗位的需求热力图，回答"哪里机会多"；
2. **比较**：薪酬分布与经验 / 学历的关系，回答"同样的岗位，差距出在哪"；
3. **决策**：把前两步的筛选结果收敛成一张目标岗位画像卡。

本节只是设想，不代表已完成的设计。
